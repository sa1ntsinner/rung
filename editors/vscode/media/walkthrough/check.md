# Check this computer

rung sync needs licensed TIA Portal V19, V20 or V21 with Openness, your Windows user in **Siemens TIA Openness**, and the selected bridge registered in TIA's whitelist. The Environment view lists the checks and offers fixes, including whitelist registration. **TIA sync ready** means all required checks passed; running the check alone does not complete this step.

Without TIA Portal, the language server, the tables and the offline tests still work.
