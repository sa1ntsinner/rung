# Contributing

- Every commit needs a DCO sign-off (`git commit -s`), certifying the [Developer Certificate of Origin](https://developercertificate.org/).
- Contributions to BUSL directories additionally require the [CLA](CLA.md).
- MIT directories: `packages/bridge-client`, `grammars/`, `editors/`, `agents/`, `docs/format/`, `tools/`. Everything else in core is BUSL-1.1 (see `LICENSE`).
- Every source file starts with the SPDX header for its directory; `pnpm lint` checks it.
- Never commit TIA projects, exports or code that you do not own. Test fixtures are generated by `tools/fixtures` only.
- Tests: `pnpm test` (TypeScript), `dotnet test bridge/tests/Rung.Bridge.Core.Tests` (bridge core). Adapter integration tests need a licensed TIA Portal and run on a trusted host only.
