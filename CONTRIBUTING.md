# Contributing

- Every commit needs a DCO sign-off (`git commit -s`), certifying the [Developer Certificate of Origin](https://developercertificate.org/).
- Contributions to BUSL directories additionally require the [CLA](CLA.md).
- MIT directories: `packages/bridge-client`, `grammars/`, `editors/`, `agents/`, `docs/format/`, `tools/`. Everything else in core is BUSL-1.1 (see `LICENSE`).
- Every source file starts with the SPDX header for its directory; `pnpm lint` checks it.
- Never commit TIA projects, exports or code that you do not own. Test fixtures are generated by `tools/fixtures` only.
- Tests: `pnpm test` (TypeScript), `dotnet test bridge/tests/Rung.Bridge.Core.Tests` (bridge core). Adapter integration tests need a licensed TIA Portal and run on a trusted host only.

## Live tests against TIA Portal

They run headless: no TIA window and no Openness prompt. You need TIA Portal V20 and membership in the "Siemens TIA Openness" group.

```bat
:: once per machine, elevated: lets builds keep the Openness whitelist current
powershell -ExecutionPolicy Bypass -File tools\openness\Register-OpennessWhitelist.ps1 -GrantUser %USERNAME%

dotnet build bridge/src/Rung.Bridge.V20 -c Release
powershell -ExecutionPolicy Bypass -File tools\fixtures\New-FixtureProject.ps1
start /b powershell -ExecutionPolicy Bypass -File tools\fixtures\Start-FixtureHost.ps1
set RUNG_PROJECT=%USERPROFILE%\rung-fixtures\RungFixture\RungFixture.ap20
dotnet test bridge/tests/Rung.Bridge.V20.IntegrationTests --filter Category=Tia
set RUNG_E2E=1 && pnpm vitest run tests/e2e
powershell -ExecutionPolicy Bypass -File tools\fixtures\Start-FixtureHost.ps1 -Stop
```

Downloads run against S7-PLCSIM V20, also without a window: the script starts PLCSIM on its own Windows desktop with one powered-on S7-1500. TIA Portal lists the PLCSIM interface only if it starts after PLCSIM.

```bat
node tools\fixtures\plcsim.mjs start
powershell -ExecutionPolicy Bypass -File tools\fixtures\New-FixtureProject.ps1 -Name RungPlcsim -Runnable
start /b powershell -ExecutionPolicy Bypass -File tools\fixtures\Start-FixtureHost.ps1 -Name RungPlcsim
set RUNG_E2E_PLCSIM=1 && pnpm vitest run tests/e2e/plcsim.e2e.test.ts
powershell -ExecutionPolicy Bypass -File tools\fixtures\Start-FixtureHost.ps1 -Name RungPlcsim -Stop
node tools\fixtures\plcsim.mjs stop
```
