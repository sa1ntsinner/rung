            Built-in safeguards
            

              
                
Project accessThrough Siemens Openness; project files are never opened directly

                
ImportsRevision checked first, inside a TIA transaction

                
ConflictsSync stops for a person

                
Deleted fileThe block stays until rung confirm-delete

                
Protected objectsFailsafe, know-how protected, system, GRAPH and library instances are read-only

                
DownloadsA person starts each one and allows every risky TIA question by name

              
            

          

          
Agent instructions do not restrict a shell: an agent with one has your permissions. Keep a PLC out of an agent’s reach.

How a project connects

          
Open a TIA Portal project, link a folder to it, then pull and sync its files.

          
Pre-release: there is no public release yet. The quickstart describes the setup of the first one.

          

            Read quickstart
            
          

        


$ rung init --project D:\TIA\Line3.ap20   # link the folder
$ rung pull                               # export to files
$ rung watch                              # keep both sides in sync
